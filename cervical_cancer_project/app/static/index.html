End-to-end workflow

  1. Grouped source-aware splitting prevents related crop leakage.
  2. ResNet-18 and EfficientNet-B0 learn cytology categories independently.
  3. Three-view TTA averages orientation-invariant predictions.
  4. Validation-selected 95:5 probability fusion forms the image hybrid.
  5. Grad-CAM and clinical drivers explain both modalities.
  6. Image consensus and Random Forest risk generate the multimodal score.
